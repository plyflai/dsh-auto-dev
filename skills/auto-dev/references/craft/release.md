# 发布准备

在用户要求正式发布或构建候选版本时使用。先区分本地实现、隔离候选与正式目标。

## 核对真实边界

明确目标版本、实际加载入口、配置与必要依赖。运行受影响测试、构建和目标环境检查；保留可核对的产物与运行回执。源代码通过不等于目标已经加载。

正式发布前准备具体可审查结果：变化、验证、已知限制、部署动作与恢复方法。需要批准时让用户批准这个结果。既有授权已覆盖的隔离测试继续执行，不重复索要许可。

只在实际不可逆、跨系统、权限或正式发布边界执行必要检查。普通本地缺陷继续修复；缺少外部权限或关键前提时明确阻塞，不因调查次数停止工作。

## 产出

分别报告 source、package、runtime 与正式发布状态。候选安装不得冒充 stable 发布；未做效率或 token 测量就不报告收益。恢复方案必须说明覆盖范围，不能宣称文件检查点会恢复数据库、服务或外部状态。
