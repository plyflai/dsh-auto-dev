# 界面验收

在改动布局、交互、表单、导航或状态呈现时使用。先确定用户需要观察的表面。

## 按影响选验证

- `static`：编译、类型或解析检查。证明代码可构建。
- `logic`：守卫、状态、数据与表单测试。证明指定逻辑。
- `browser`：真实页面操作和截图。证明运行中的交互与呈现。

单元显式声明的档位必须兑现；不把静态或逻辑结果写成真实浏览器通过。小文案修改无需机械跑遍所有交互；涉及跨页、异步、错误或权限时，检查被影响的路径。

## 真实操作

打开实际产物，走关键用户路径。核对加载、成功、空值、失败和等待中实际受影响的状态。检查对话回执与面板是否表达同一事实。

截图每轮使用新文件名，发送前自己查看。需要用户检查变化时同时提供可打开的页面。记录版本、URL、操作与观察；截图不能替代未运行的功能检查。

无法运行时说明缺少的具体条件。能继续处理的本地问题继续修复；实际外部前提缺失时才等待。
